# Меню ресторана BARIN — сайт

Простой статический сайт (HTML/CSS/JS, без сборки) с полным меню ресторана.
Открывается как обычная веб-страница — не требует сервера, базы данных
или установки чего-либо.

## Структура файлов

```
index.html          — сама страница
assets/styles.css   — оформление
assets/app.js       — логика (рендер меню, навигация, скролл)
assets/menu-data.js — весь текст меню (цены, названия, переводы)
assets/logo.webp, decor.webp, decor-mirror.webp — изображения
```

Чтобы изменить меню (цены, блюда, переводы) — правьте только
`assets/menu-data.js`, ничего больше трогать не нужно.

## Как выложить на GitHub Pages (бесплатный хостинг)

1. Зайдите на [github.com](https://github.com) и создайте новый репозиторий
   (New repository). Имя, например: `barin-menu`. Сделайте его Public.
2. Загрузите все файлы из этой папки в репозиторий — на странице
   репозитория нажмите **Add file → Upload files**, перетащите все файлы
   и папки (`index.html`, `assets/`), и нажмите **Commit changes**.
3. Зайдите в **Settings** репозитория → раздел **Pages** (слева в меню).
4. В разделе **Build and deployment** выберите **Source: Deploy from a
   branch**, ветку **main**, папку **/ (root)** → **Save**.
5. Подождите 1–2 минуты. GitHub покажет ссылку вида:
   `https://ваш-логин.github.io/barin-menu/`
   Это и есть публичный адрес меню — его можно открыть с любого телефона
   или компьютера, а также сделать QR-код на него для столов.

## Проверить локально перед загрузкой

Дважды кликнуть на `index.html` — откроется в браузере. Либо, если есть
Python: `python3 -m http.server` в этой папке и открыть
`http://localhost:8000`.
